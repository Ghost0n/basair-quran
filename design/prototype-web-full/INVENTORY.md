# Inventory: what the Basair web app does today (branch feat/Q-Basair-52-mobile-native-ux-ipa)

Source: a read of apps/web on 2026-10-21. Production (`origin/main`) still runs the older single-page search tool;
everything below exists on the branch. Labels are quoted from the code.

## 1. Global chrome
- Single route `/` with `?mode=`: home (default), reading, search, studio, notebook, heatmap, board, document, community, post, saved, index, settings. Also /login, /welcome, /about, /guidelines.
- Three "worlds" tint the UI: gold (reading), teal (research), copper (community).
- Desktop rail: brand mark (Home) · divider · "المصحف" · "الفهرس" · "المحفوظة" · divider · "البحث" (also lit on heatmap) · "الدراسة" · "الدفتر" (also lit on board, document; reopens last notebook page) · divider · "المجتمع" (also post) · spacer · "السمة" (tooltip "التبديل إلى السِّمة الفاتحة/الداكنة") · "إعدادات" · Account: guest "دخول" → /login; signed in avatar medallion "حسابي" → popover (avatar, name, email, "الإعدادات والأجهزة ›", status dot "محفوظاتك تُزامَن تلقائياً", "تسجيل الخروج").
- Phone bottom bar: Home (logo) · "المصحف" · "البحث" · "الدراسة" · "الدفتر". Community via Home tiles.
- Command bar: placeholder "ابحث · انتقل · اسأل  —  /"; live intent chip "اسأل ✦" / "انتقل" / "جذر · ابحث"; Enter on a question → Studio with it queued; on a reference (page, surah, surah:ayah, juz) → reader; else search. Mode prefix chip "جذر"/"عبارة"/"كلمة". Suggestions listbox labelled جذر/عبارة/كلمة.
- Shortcuts: ⌘K or `/` opens search; `?` opens "اختصارات لوحة المفاتيح" (فتح شريط الأوامر، عرض اختصارات لوحة المفاتيح، إغلاق النوافذ المنبثقة); Esc closes.
- Theme: dark (default) / light only. Languages: 24 (ar reviewed, others "· β"). Numerals: "هنديّة ٠١٢" / "لاتينية 012" / "فارسيّة ۰۱۲".
- No notifications/inbox. Merge toast after guest sign-up: "ضممنا محفوظاتِ الضيف إلى حسابك" + counts "{n} آية مُثبَّتة · {n} جلسة بحث · {n} جذر مُتابَع" "— أصبحت تُزامَن", "تراجَع" with 30s ring; after undo "أُلغي الضمّ — بقيت محفوظات الضيف محليّةً على هذا الجهاز".

## 2. Home
Greeting by time ("صباح الخير[، name]" / "مساء الخير", "رمضان كريم", "عيد مبارك", "مرحباً بعودتك" after 7+ days, "أهلاً بك في بصائر" first visit) + Hijri date. Rotating verse (wide only, 5 verses, 9s). Continue card "تابع القراءة" (surah or "صفحة n", meta "صفحة n · time", ▶ "استمع من حيث توقفت", "تابع"); first time "ابدأ القراءة" / "الفَاتِحَة" / "من أول المصحف" / "ابدأ". Tiles: "الفهرس"/"كل السور", "المحفوظة"/"الصفحات المحفوظة", "تابع دراستك"(last session) or "الدراسة"/"جلسة جديدة", "المجتمع" ("{n} منشور جديد" or "ما يشاركه الباحثون", dot). Search pill "ابحث بكلمة أو جذر، أو اطرح سؤالاً". Account sheet "الحساب والإعدادات". Sections hideable in Settings → «الرئيسية».

## 3. Reader (mode=reading)
- Wide (>1000px): the Mushaf is always present; search, studio, notebook, index, saved open as panels BESIDE it. ≤1000px: single screen.
- Reader bar: identity button (surah, "الجزء n، صفحة n من 604") → «انتقل»; tool picker قراءة / تحديد / تظليل (keys 0/1/2); search button; "انتقل"; "العرض"; play page ("تلاوة الصفحة"/"إيقاف التلاوة"); bookmark (verse mode) — in pages mode the page has a corner ribbon (outline/red) "احفظ هذه الصفحة"/"إزالة الصفحة من المحفوظات"; focus mode "وضع التركيز (F)"; page arrows ‹ › (PageUp/PageDown); thin progress line; edge page-turn zones.
- Tools: "قراءة" (text inert); "تحديد" ("اضغط كلمة لتحليلها، أو كلمة ثم أخرى، أو رقم الآية لتحديدها كاملة"): selection bar with «text», word count, reference, ✕ "إلغاء التحديد (Esc)"; single word → analysis grid "الجذر" / "الأصل" / "القسم" / "الإعراب" + features ("لا يتوفّر تحليل صرفي لهذه الكلمة."); actions "بحث بالعبارة", "مواضع الجذر", "اسأل الدراسة" (queues "ما دلالة «…» في سورة … (الآية …)؟"), "إحصاء" (counts of phrase and each letter by الصفحة / السورة / القرآن), "نسخ مع المرجع" → "نُسخ". "تظليل" ("اضغط آية: احفظها وظلِّلها بموضوع") → «حفظ وتظليل» sheet. Tools locked during recitation ("الأدوات متوقفة أثناء التلاوة").
- «العرض» strip: "طريقة القراءة (Shift+M)": "صفحات" ("صفحة المصحف كما طُبعت"; single page or two-page spread when room) / "آية آية" ("كل آية في سطر"); text size slider 18–48; toggle "تظليل المواضيع".
- Verse-by-verse: calligraphic surah title frame + basmala at surah start, verse number chips, up to 3 translations under each verse (translator/source, "حواشٍ" expander), "صفحة n" markers.
- Edition: only "مصحف المدينة النبوية" — "رواية حفص عن عاصم · صفحات مجمّع الملك فهد". No classical tafsir.
- «انتقل» sheet (same component as the Index page): field "اسم السورة أو رقمها · ٢:٢٥٥ · صفحة ٥٠" (filters + "انتقل إلى …"); tabs "المحفوظة" (saved pages "surah · صفحة n · age", swipe delete; empty "احفظ صفحة من القراءة (علامة الحفظ في شريط القارئ) لتجدها هنا.") / "السور" (number, name, مكّيّة/مدنيّة, ayah count; empty "لا توجد سورة بهذا الاسم.") / "الأجزاء" (grid 30) / "الأحزاب" (grid 60 with start) / "صفحة" ("رقم الصفحة (١–604)" + "انتقال"). Current surah/juz/hizb highlighted.
- Focus mode pill "صفحة n ⤡" ("إنهاء وضع التركيز"). Long jumps: travel overlay with gold wash + page counter. Resume at last verse. Keys PageUp/PageDown, Shift+M, F, Esc, 0/1/2, arrows between words, Enter/Space act. Loading "جارٍ تحميل المصحف"; error card with retry.

## 4. Recitation
Desktop media bar "شريط التلاوة": "الآية السابقة", play/pause, "الآية التالية"; reciter dropdown "اختيار القارئ" (search "ابحث عن قارئ…"); subtitle "سورة X، آية n" or "جاهز — اختر قارئاً ثم شغّل"; seek bar "موضع التلاوة" with times; chips "نطاق التلاوة" (tabs الصفحة/السورة/الجزء/الحزب/مخصّص, من/إلى, "تكرار النطاق", "تلاوة النطاق", "إلغاء النطاق"), "تكرار" (verse), speed 0.75/1/1.25/1.5×, ✕ "إغلاق شريط التلاوة". Recited verse lit and followed. No sleep timer, no web downloads.

## 5. Search / concordance (mode=search) — panel "لوحة المطابقة" beside the Mushaf on desktop
Header kicker "المطابقة", root or term, meta "{n} موضع، {n} آية" or "اكتب جذراً أو كلمة في شريط الأوامر"; ↺ "بحث جديد"; ✕ close. Modes root / exact (جذر / كلمة / عبارة); no surah/juz/POS filters today. Empty: "اكتب جذراً أو كلمة قرآنية في شريط الأوامر بالأعلى ↑ لتبدأ البحث." + "جرّب" chips "الحمد", "صراط مستقيم", "كتب" + "ب · ص · ر" watermark. Summary: root, "جذر قرآني"/"بحث لفظي" · "{n} مجموعة", stats موضع/آية/سورة, "تابِع هذا الجذر" → "جذر مُتابَع", "خريطة انتشار الجذر" → heatmap. Grouped results; verse rows "سورة X", "s:a", ▶ "تلاوة الآية", pin "ثبّت في الدفتر"/"مثبّت في الدفتر" (→ «حفظ وتظليل»), text with highlights; per-group pager "السابق n / N التالي". Desktop: tapping a result loads that verse in the Mushaf. States: skeletons; "هل تقصد:"; "لا توجد نتائج لهذا البحث."; "حدث خطأ في الاتصال بالخادم.".

## 6. Heatmap (mode=heatmap&root=)
Back, kicker "خريطة انتشار الجذر", root, "{n} موضع · {n} سورة"; grid of 114 surah cells in 7 shades (tap → reader at that surah); "السُّوَر الأعلى ذِكراً" top 4; states "جارٍ حساب الانتشار…", "لا توجد مواضع لهذا الجذر.", "اختر جذراً من لوحة المطابقة لعرض انتشاره عبر المصحف.".

## 7. «حفظ وتظليل» sheet (save a verse with topic themes)
Title, "سورة X، الآية n", verse preview; "المواضيع": toggle chips with colour dot (hint when none: "ظلِّل الآية بموضوع لتجتمع الآيات المتقاربة معاً في الدفتر، ثم أنشئ لها لوحة لربطها."); per selected theme "لوحات «X»"; "موضوع جديد": name ("مثلاً: الصبر، آيات الخلق…") + "إضافة" + 8 swatches أخضر/أزرق/وردي/بنفسجي/فيروزي/رملي/ذهبي/رمادي; footer "إزالة من الدفتر" (if saved) and "تمّ" (nothing saved until تمّ).

## 8. Study (mode=studio) — panel beside the Mushaf on desktop
Session tabs (✦ title ×, "+" "جلسة جديدة"). Header kicker "جلسة الدراسة", title → "الجلسات" sheet; meta "{n} رسالة · القرآن وحدَه" / "· قراءة تفسيرية"; icons "حوّل إلى بحث" (confirm banner "حوّل هذه الجلسة إلى بحث قابل للتحرير؟ تبقى الجلسة كما هي."), "تصدير الجلسة", gear "إعدادات النموذج" (مفتاح الوصول، عنوان الخدمة، نموذج المحادثة), close. Modes "القرآن وحدَه" (strict, gold) / "قراءة تفسيرية" (copper) with disclaimer "قراءة تفسيرية تجريبية" + "تنبيه — ما يَلي قراءة تفسيرية بشرية مُولَّدة من نموذج لغوي. ليست حُجَّة شرعية ولا تَنُوب عن أهل العلم. الدليل الوحيد المُعتَمَد هنا هو القرآن الكريم.". Focus note "الآية المقصودة: … ، تُقرأ مع ما قبلها وما بعدها وسياق السورة.". Thread: "السؤال" bubbles; answers "جواب — مستند على القرآن وحدَه" or Tafssir sections الخلاصة / التحليل اللغوي / ربط الآيات / الرؤية المستفادة / حدود القراءة; evidence "الدليل القرآني ({n} آية)" numbered [1]… "سورة X: n" + text with highlights; clicking jumps the Mushaf. Agent may ask a clarifying question. Empty: "اطرح سؤالاً حرّاً — يُحوّله الباحث إلى ألفاظ قرآنية، يعرض الآيات الأقرب، ثم يصوغ الجواب منها.". Working: "يجري تحليل الآيات…". Composer "تابع البحث، أو اطرح سؤالاً جديداً…" (Enter sends, Shift+Enter newline), depth سريع / متوازن / عميق (Tafssir), "اسأل". Guest gate modal "الدراسة تتطلّب حساباً" ("أنشئ حساباً", "تسجيل الدخول", "لاحقاً"). Export modal "تصدير الجلسة": Markdown, JSON (PDF/DOCX "قريباً"); "تضمين الآيات المُستدَل بها", "تضمين تنبيه الوضع التفسيري"; "معاينة", "إلغاء", "تصدير". Errors "تعذّر الاتصال بخدمة الباحث الذكي.".

## 9. Notebook (mode=notebook&tab=verses|boards|documents|sessions|roots) — beside the Mushaf on wide screens
Header "الدفتر", "{n} آية، {n} بحث، {n} جلسة، {n} جذر". Tabs "الآيات", "اللوحات", "الأبحاث", "الجلسات", "الجذور".
- الآيات: "الأحدث" / "حسب الموضوع"; rows surah n, theme dots, snippet, age, delete; by theme: card per theme (dot, name, count, "اللوحات", ✎ rename/recolour/"حذف الموضوع" → "حذف الموضوع؟ تبقى آياته محفوظة.", mini verses "الآية كاملة"/"أقلّ"); "بلا موضوع"; empty "لا توجد آيات محفوظة بعد. احفظ آية من القراءة أو من نتائج البحث.".
- اللوحات: per theme "اللوحات: n"; board rows name, ayah count, age, ✎, 🗑; "لوحة جديدة" (name, "إنشاء"/"إلغاء"); empties.
- الأبحاث: "+ بحث جديد"; rows title, "{n} قسم، {n} آية، age", "، من الدراسة"/"، من لوحة"; empty "لا أبحاث بعد. حوِّل جلسة من الدراسة، أو صدِّر لوحة موضوع، أو ابدأ بحثاً جديداً.".
- الجلسات: filters الكل / القرآن وحدَه / تفسيرية; rows open Studio; empty "لا توجد جلسات محفوظة في هذا التصنيف.".
- الجذور: row → heatmap; "إلغاء المتابعة"; empty "لا توجد جذور مُتابَعة بعد. تابِع جذراً من لوحة المطابقة.".

## 10. Theme board (mode=board) — full width
Top bar: back "العودة إلى الدفتر", editable board name, theme name, "لوحة الموضوع، n آيات"; tools "تراجع (Ctrl+Z)", "إعادة (Ctrl+Y)", "ملاحظة", "عنوان", "شكل" (مستطيل / شكل بيضاوي / معيّن), "الآيات" (panel, hidden-count badge), "حذف", "ترتيب" (Mushaf order), "صدّر كبحث"; save state "جارٍ الحفظ…"/"محفوظ"/"تعذّر الحفظ". Canvas: dotted bg, zoom controls, minimap; nodes: ayah cards ("عرض السياق"/"طيّ السياق", "افتح في المصحف"), notes ("ملاحظة…"), headings ("عنوان…"), shapes ("نص…"); drag to move; drag between nodes to link; click link → "نوع العلاقة": يفسّر / يؤكّد / يقابل / سبب ← نتيجة / مثال / يتكرّر في / "وصف آخر…" + "تمّ", "حذف العلاقة". Ayah nodes hide only ("إخفاء من اللوحة (تبقى في الموضوع)"). Style: لون النص / الخلفية / الإطار (متصل/متقطّع/بلا) / لون الإطار / الحجم (S M L XL) / الخط (نسخ/كوفي/بسيط), six colours + "افتراضي", "إعادة التنسيق". "آيات الموضوع" panel to hide/show verses. Empty "لا آيات في هذا الموضوع بعد. ظلِّل آيات بهذا الموضوع من القراءة (أداة «تظليل») لتظهر هنا.".

## 11. Research document editor (mode=document&id=)
Bar: back, editable title "عنوان البحث", kicker "بحث" + "، من الدراسة"/"، من لوحة موضوع", save state ("العنوان مطلوب للحفظ"), "مشاركة", "جاهزية النشر", "نشر". Body: summary "ملخّص قصير للبحث…"; "{n} قسم، {n} آية، الإصدار n"; Tafssir disclaimer if from Tafssir; embedded board "لوحة الموضوع" + "عدّل اللوحة"; mismatch warning "بعض النصوص المقتبسة لا تطابق نص المصحف — راجِعها في الأقسام المعلَّمة."; audit box "البحث جاهز للنشر"/"قبل النشر:" with checks نصوص الآيات مطابقة للمصحف / للبحث عنوان ومحتوى / الأقسام المولَّدة آلياً موسومة / القراءة التفسيرية تحمل التنبيه / مراجع الآيات صحيحة. Sections kinds نص / آيات / ملاحظة / سؤال / جواب آلي: optional title, "إلى الأعلى"/"إلى الأسفل", "حذف القسم", body; ayah refs with "بطاقة", "إزالة الآية من القسم", problems "هذه الآية غير موجودة في المصحف." / "النص المقتبس لا يطابق المصحف." + "استبدل بنص المصحف"; "أضف آيات"; bottom "أضف:" آيات / نص / ملاحظة / سؤال. "المراجع": كتاب / تفسير / آية / رابط, "اسم المرجع", "الموضع (جزء/صفحة/رابط)", "إضافة", "حذف المرجع", empty "لا مراجع بعد.". "حذف البحث" → "حذف البحث نهائياً؟". Share studio "مشاركة البحث": بطاقة البحث / بطاقة آية / سلسلة شرائح / طباعة / PDF; size "منشور ٤:٥"/"مربّع"/"قصّة ٩:١٦"; style "ليلي"/"ورقي"; "مشاركة", "تنزيل ZIP", "طباعة / حفظ PDF". Publish sheet "نشر في المجتمع": "من يرى البحث" "عامّ" / "برابط فقط"; checkbox "قرأتُ إرشادات المجتمع وألتزم بها، وأتحمّل مسؤولية ما أنشر."; "انشر البحث" ("جارٍ الفحص…"); outcomes "يحتاج البحث إلى تعديل قبل النشر" / "نُشر البحث" / "أُرسل البحث للمراجعة" + "افتح المنشور"; guest "سجّل الدخول لتنشر في المجتمع.".

## 12. Community (mode=community&tab=saved|mine|moderation)
Hero kicker "المجتمع", "أبحاث يتشاركها المتدبّرون", line about checks/guidelines, "+ شارك بحثاً". Tabs "الموجز", "المحفوظة", "منشوراتي" (signed in), "الإشراف" (admins). Feed tools: search "ابحث في العناوين والملخّصات والوسوم…", sort "الأحدث"/"الأبرز" (default الأبرز), "تصفية" (surah "كل السور", type الكل / القرآن وحدَه / تفسيرية, toggle "بلوحة موضوع"), popular tags #tag, active filter pills + "مسح الكل". Post card: avatar initial, author (tap filters "منشورات هذا الباحث"), age · "قراءة {n} د", badges "تفسيرية تجريبية", "لوحة", in mine status قيد المراجعة / منشور / مطلوب تعديل / مرفوض / مسحوب / أُزيل + "برابط فقط"; title, summary, quoted verse ﴿surah: n﴾, tags; footer ♥ ("أعجبني"/"إلغاء الإعجاب"), comments, "{n} آية", save ("احفظ"/"إزالة من المحفوظة"), "شارك الرابط".
